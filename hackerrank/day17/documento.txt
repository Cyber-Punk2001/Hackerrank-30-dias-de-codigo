Objetivo

El reto de ayer te enseñó a manejar situaciones excepcionales utilizando bloques try y catch. En el reto de hoy, practicarás cómo lanzar y propagar una excepción.

Consulta la pestaña Tutorial para obtener material de aprendizaje y un video explicativo.

Tarea

Debes crear una clase llamada Calculator con un único método:

int power(int n, int p)

El método power recibe dos números enteros, n y p, como parámetros y debe devolver el resultado entero de:

n^p

Es decir, debe calcular n elevado a la potencia p.

Ejemplos:
3^5 = 243
2^4 = 16

Si n o p son negativos, el método debe lanzar una excepción con exactamente este mensaje:

n and p should be non-negative

Esto significa:

n y p deben ser valores no negativos.

Nota

No debes utilizar un modificador de acceso como public al declarar la clase Calculator.

Formato de entrada

La entrada estándar es manejada automáticamente por el código proporcionado por HackerRank.

La primera línea contiene un número entero T, que representa la cantidad de casos de prueba.

Las siguientes T líneas contienen dos números enteros separados por un espacio:

n p

donde:

n es el número que se elevará a una potencia.
p es el exponente.
Restricciones

Ningún caso de prueba producirá un desbordamiento (overflow) si el código está correctamente implementado.

Formato de salida

La salida también es manejada automáticamente por el código proporcionado por HackerRank.

Habrá T líneas de salida.

Cada línea debe contener:

El resultado de n^p, si ambos valores son válidos.
n and p should be non-negative, si n o p son negativos.
Entrada de ejemplo
4
3 5
2 4
-1 -2
-1 3
Salida de ejemplo
243
16
n and p should be non-negative

Explicación
Caso 1
n = 3
p = 5

Ambos valores son positivos, por lo que se calcula:

3^5 = 243

Resultado:

243
Caso 2
n = 2
p = 4

Ambos valores son positivos:

2^4 = 16

Resultado:

16
Caso 3
n = -1
p = -2

Ambos valores son negativos.

Por lo tanto, el método debe lanzar una excepción y mostrar:

n and p should be non-negative
Caso 4
n = -1
p = 3

Aunque p es positivo, n es negativo.

Por lo tanto, también se debe lanzar una excepción:

n and p should be non-negative
